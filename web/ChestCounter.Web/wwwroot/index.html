ChestCounter Web

Conta os baús dos seus replays do Fortnite. Os arquivos são lidos aqui no navegador e não saem do seu computador.

Arraste aqui os arquivos .replay, um .zip com eles ou a pasta inteira

No PC do jogo eles ficam em %LOCALAPPDATA%\FortniteGame\Saved\Demos

Clique em Escolher pasta, cole o caminho na barra de endereço da janela e aperte Enter.

Para reler com um clique: escolha uma pasta e ela fica lembrada neste navegador. O navegador não permite isso para pastas dentro de AppData (onde o Fortnite grava); funciona com uma pasta para onde você copia os replays, como Documentos.

Carregando o analisador… os botões são liberados quando terminar.
